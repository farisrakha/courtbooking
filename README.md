# INA Sports · Booking Lapangan

Court-booking web app for INA Sports venues (Senayan, Cibubur). Next.js 16 · React 19 · Tailwind v4.

```bash
npm install
npm run dev -- --port 3001   # http://localhost:3001
npm run check && npm run lint && npm run build
```

See `PRODUCT.md` for the brief and journey, and `CLAUDE.md` for architecture notes.
Demo mode: no backend or payment gateway yet. Bookings are saved in the browser's localStorage.
